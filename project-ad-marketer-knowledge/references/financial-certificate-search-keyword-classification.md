# 금융·공동·조달 인증서 검색광고 키워드 분류

## 2026-11-02 변경 요약

### 1) 새로 학습한 사실

- 금융결제원 검색광고 핵심어로 제시된 범위는 `금융인증서`, `공동인증서`, `조달청인증서`, `나라장터인증서`였다.
- 네이버 키워드도구 연관어는 연관성이 보장된 목록이 아니므로, 문자열 포함 여부만으로 등록하면 일반 조달 업무, 경쟁 인증기관, 보안토큰, 무관 인증·증명 수요가 섞인다.
- 공동·공인인증서의 발급·갱신·복사·관리 표현은 직접 운영 후보가 될 수 있다. 기업·법인·사업자용, 전자세금계산서용, 특정 기관·은행용, 무료·할인 탐색어는 제공 범위와 랜딩 확인 전까지 조건부로 둔다.

### 2) 기존 지식에서 수정할 점

- `공동인증서` 또는 `공인인증서`가 포함됐다는 이유만으로 모두 운영 가능으로 분류하지 않는다.
- `나라장터`, `조달청`, `입찰`이 포함돼도 인증서 발급·갱신 의도가 없으면 검색광고 대상에서 제외한다.
- 과거 명칭인 `공인인증서` 검색어는 공동인증서 수요로 연결될 수 있으나, 광고 소재와 랜딩에서 현재 명칭과 관계를 정확히 설명한다.

### 3) 실무 적용 원칙

1. 핵심어와 발급·갱신·복사·관리 등 직접 행동어를 1차 운영군으로 둔다.
2. 기업·법인·사업자, 세금계산서, 특정 은행·기관, 비용·무료·할인은 조건부 그룹으로 분리한다.
3. 경쟁 인증기관명, 일반 입찰·업체등록·공고, 보안토큰 구매, 무관 인증·증명은 제외한다.
4. 조건부 키워드는 실제 제공 서비스, 랜딩페이지, 수수료 표현을 확인한 뒤 소액으로 운영한다.
5. 연관키워드 목록이 핵심어 수와 맞지 않으면 임의 보완하지 않고 실제 제공된 핵심어 기준임을 명시한다.

### 4) 제안서/리포트 문장 예시

> 핵심 인증서와 발급·갱신 의도가 직접 연결되는 키워드부터 운영합니다. 기업용·세금계산서용·기관별 인증서 키워드는 실제 제공 범위와 랜딩페이지가 일치하는 경우에만 별도 그룹에서 테스트합니다.

> 나라장터·조달청 관련 검색어는 인증서 수요와 입찰 절차 수요가 섞여 있습니다. 인증서 발급·갱신 의도가 확인되는 키워드만 등록하고 입찰공고·업체등록·보안토큰 검색어는 제외합니다.

### 5) 다음 확인 필요사항

- 요청문에 언급된 11개 핵심키워드 중 실제로 제시되지 않은 7개
- 금융결제원이 광고 랜딩에서 제공·안내할 기업·법인·세금계산서용 인증서 범위
- 무료·할인·가격 표현에 사용할 수수료와 혜택 근거
- 특정 은행·기관별 이용 안내 랜딩 보유 여부

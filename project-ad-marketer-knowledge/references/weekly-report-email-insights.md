# Weekly Report Email Insight Reference

Use this reference when writing or reviewing Korean weekly ad-report emails for GabiaCNS-style clients, especially when the report must summarize performance, explain causes, propose next actions, or request client confirmation.

Source examples reviewed on 2026-06-29:

- I-store DA weekly report email, 2026-06-22 to 2026-06-28.
- Lingtea 11st weekly report email, 2026-06-22 to 2026-06-28.
- Shinil Biaf Naver ad setup/report email, 2026-06-29.

These are internal style examples, not official platform documentation.

## Core Learning

A weekly report email should not only attach a report file. It should make the next operational decision easier.

Good structure:

1. Reporting period and current budget/status.
2. One-line headline result.
3. Medium or placement-level interpretation.
4. Cause or likely reason, clearly marked when inferred.
5. Concrete next action.
6. Client confirmation items, if action needs approval or assets.

## Three Report Types

### 1. DA Media Comparison Type

Use when multiple display/social/programmatic media are running together.

Read by:

- media;
- placement;
- device;
- time slot;
- conversion event depth;
- budget exhaustion timing.

Key interpretation rules:

- Do not judge DA only by purchase conversion when upper/mid-funnel events such as signup, cart add, inquiry click, or form submit are tracked.
- If one medium has high clicks and low CPC but weak final conversion, call it "traffic volume contributor" rather than "best medium."
- If another medium has high CTR but shallow conversion events, call it "creative/interest response is strong, but purchase validation remains."
- If a medium has high CPC and low traffic, propose device/placement exclusion or budget reduction before full stop.
- When budget exhausts early, check whether the profitable or meaningful time slots are being missed later in the day.

Useful wording:

```text
이번 주는 모비온에서 구매 전환이 발생했으나, 매체별 역할은 다르게 해석할 필요가 있습니다. 모비온은 유입량과 구매 전환 측면에서 강점이 있었고, 인스타그램은 CTR과 장바구니 추가 반응이 높아 소재 반응 검증 매체로 볼 수 있습니다. 반면 구글은 CPC가 높고 유입 규모가 낮아 태블릿/TV 등 저효율 지면을 제외하고 PC·모바일 중심으로 압축 운영하는 방향이 적합합니다.
```

### 2. Open-Market Weekly Performance Type

Use when marketplace sales ads are reviewed weekly.

Read by:

- weekly total trend;
- event/promotion baseline;
- product-level cost, revenue, ROAS, CVR;
- AI recommendation/search split;
- brand-keyword defense;
- new product addition opportunity.

Key interpretation rules:

- Do not compare event weeks with ordinary weeks without labeling the event effect.
- If ROAS rebounds after cost reduction, identify whether it is true growth or cost-control recovery.
- If a timed deal raises sales but ROAS remains only moderate, call it event-supported performance rather than structural improvement.
- If AI campaign ROAS falls below the internal threshold, propose product addition/exclusion or promotion-support tests only after checking discount risk.
- For beverage/repeat-purchase products, compare flavor, package, volume, and new product variants separately.

Useful wording:

```text
이번 주는 타임딜 영향으로 전주 대비 구매수와 구매금액은 회복되었으나, 전환율은 큰 폭으로 개선되었다고 보기는 어렵습니다. 브랜드 키워드 순위 방어는 유지하되, AI 추천 영역에서는 효율 하락 상품과 신규 상품의 테스트 필요성을 나누어 보는 것이 좋습니다. 특히 신규 출시 상품은 기존 주력 상품과 같은 예산 안에서 섞기보다 별도 테스트 구간을 두어 클릭률과 구매 전환을 먼저 확인하는 방향을 제안드립니다.
```

### 3. Setup / Tracking / Approval Request Type

Use when the email is not a pure performance report but an operation-status and approval-request email.

Read by:

- what has already been set up;
- what needs client approval;
- what assets or access information are needed;
- what changes if the client does not proceed;
- why the requested setup matters.

Key interpretation rules:

- Tracking installation should be explained as optional in process but important for optimization quality.
- If conversion tracking is not installed, say that traffic/awareness campaigns can continue but conversion-based optimization and exact conversion reporting will be limited.
- For real estate or pre-sale accounts, day-of-week budget scheduling can be proposed when weekend inquiry tendency is known or likely, but it should be framed as a hypothesis to validate.
- Search ad copy and assets should be sent as confirmation items, not hidden inside the attachment only.

Useful wording:

```text
전환추적 설치는 광고 집행의 필수 조건은 아니지만, 관심고객 등록 완료와 분양문의 클릭처럼 실제 문의에 가까운 행동을 확인하고 이후 전환 목표 캠페인으로 최적화하기 위해 필요한 절차입니다. 설치를 진행하지 않을 경우 현재처럼 트래픽/인지도 중심 운영은 가능하지만, 전환 기준의 성과 판단과 유사 전환 가능 고객 최적화에는 제한이 있습니다.
```

## Quality Improvements To Apply

The reviewed emails are useful, but future emails should improve:

- Replace soft wording such as "좋을 거 같습니다" with "제안드립니다" or "우선 검토가 필요합니다."
- State whether a claim is confirmed by data or inferred from campaign changes.
- Tie every action to the KPI it is expected to improve.
- Separate "성과 해석" from "광고주 확인 요청" so the client knows what to approve.
- Avoid reporting too many raw tables in the email body; put tables in attachments and keep the email decision-focused.
- For DA, name the conversion event depth: purchase, signup, cart add, inquiry click, form completion.
- For open-market reports, distinguish event/promotion weeks from baseline weeks.

## Recommended Email Skeleton

```text
안녕하세요. 가비아CNS ○○○입니다.

○월 ○일~○월 ○일 광고 주간 리포트 전달드립니다.

이번 주 핵심 요약은 아래와 같습니다.

1. 핵심 성과
- [매체/캠페인]에서 [주요 성과]가 확인되었습니다.
- 다만 [주의할 지표]는 아직 개선 또는 추가 검증이 필요합니다.

2. 운영 인사이트
- [매체/상품/지면]은 [강점]이 확인되어 [운영 방향]으로 유지 또는 확대를 제안드립니다.
- [매체/상품/지면]은 [약점]이 확인되어 [조정 방향]이 필요합니다.

3. 차주 운영 제안
- [구체 액션 1]
- [구체 액션 2]
- [확인 필요 항목]

자세한 수치는 첨부 리포트를 참고 부탁드립니다.
확인 후 승인 또는 수정 의견 회신 부탁드립니다.
```

## Final Check Before Sending

Before sending a weekly report email, check:

- Is the key result visible within the first 5 lines?
- Are action items written as decisions, not vague observations?
- Are low-data or inferred conclusions labeled cautiously?
- Does the client know what to approve, provide, or decide?
- Are conversion tracking limits or missing setup items clearly explained?
- Are promotion/event effects separated from normal weekly performance?

# 네이버·카카오 공식 광고 업데이트 모니터링

네이버 광고와 카카오 광고의 공식 변경을 광고 제안·운영 판단에 사용할 수 있는 도메인 지식으로 누적할 때 사용한다.

## 확인 범위

- 직전 성공 점검 이후 새로 게시되거나 실질적으로 변경된 내용만 확인한다. 최초 점검은 최근 14일을 기준으로 한다.
- 네이버는 네이버 광고 공지사항, 광고 도움말·등록기준, 공식 성공전략·상품안내를 우선한다.
- 카카오는 카카오비즈니스 공지·상품안내·비즈니스 가이드, 카카오모먼트·키워드광고·커머스 광고의 공식 공지를 우선한다. 공지가 로그인 뒤에만 보이거나 수집이 제한되면 공개 공식 가이드와 회사 발표까지 확인하고 `검증 미완료` 범위를 적는다.
- 장애·점검·일시 프로모션은 장기 운영 판단에 영향이 있을 때만 포함한다.

## 판단 규칙

1. 공지일, 적용일, 테스트 기간을 분리한다.
2. 베타·일부 트래픽·일부 계정·특정 업종·특정 지면을 전체 적용처럼 표현하지 않는다.
3. UI 명칭 변경만 있는 경우 제외하되 설정·보고·검수·소재·타겟·과금 방식이 함께 바뀌면 포함한다.
4. AI 추천·예상 모수·프로파일링은 참고 정보이며 성과 보장이나 기존 픽셀·고객 DB 타겟의 대체 기능으로 설명하지 않는다.
5. 쇼핑광고의 화면상 순위·상품 수 변화는 테스트와 개인화 영향을 먼저 확인하고 입찰 문제로 단정하지 않는다.
6. 구매 가능 키워드 확대는 등록 가능성의 변화이며 검색량·성과·업종 적합성의 증거로 사용하지 않는다.
7. 같은 공지의 수정본은 새 공지로 중복 보고하지 않고 변경된 일정·범위만 갱신한다.

## 도메인 지식 반영

- 쇼핑검색·ADVoost 쇼핑 변경은 `naver-shopping-account-audit.md`에 반영한다.
- 파워링크·ADVoost·플레이스 변경은 `naver-search-advoost.md`에 반영한다.
- GFA·오디언스·전환·학습 변경은 `naver-gfa-attribution-learning-audit-202607.md`에 반영한다.
- 파워컨텐츠 변경은 `naver-power-content-efficient-keywords-202607.md`에 반영한다.
- 카카오모먼트·비즈보드·메시지·픽셀 변경은 `kakao-moment-products-2026.md`에 반영한다. 커머스 광고센터 변경은 관련 커머스 레퍼런스에 반영한다.
- 새 내용이 없으면 파일을 수정하지 않는다.

## 2026-10-28 네이버 기준선

- 11월 4일 광고주센터가 `네이버애즈(N Ads)`로 변경되지만 URL·계정·진행 광고·예산·비즈머니는 유지된다.
- 같은 날 모든 광고주에게 `맞춤 추천`이 제공되고 AI 챗봇은 `애즈 어시스턴트`로 변경된다. 맞춤 추천은 실행 버튼으로 적용할 수 있지만 AI 생성 정보가 부정확할 수 있고 성과를 보장하지 않는다.
- 미노출 문의 해결은 파워링크·쇼핑검색·플레이스검색과 ADVoost 쇼핑을 제외한 디스플레이 광고를 지원한다. 브랜드검색·신제품검색·파워컨텐츠·ADVoost 플레이스·ADVoost 쇼핑은 지원하지 않으며 순위·클릭 감소·과금 원인도 아직 지원하지 않는다.
- 공식 출처 확인일: 2026-10-28.
  - https://ads.naver.com/notice/34943

## 실무 적용 원칙

- 맞춤 추천은 계정 진단의 후보로 확인하되 즉시 일괄 적용하지 않는다. 추천 근거와 예상 성과, 현재 캠페인 목표, 예산·입찰·소재 변경 영향을 검토하고 승인 후 반영한다.
- 애즈 어시스턴트의 미노출 진단은 ON/OFF·검수·예산·잔액·기간 등 1차 원인 확인에 사용하고 순위와 성과 저하 분석은 보고서·경쟁 환경·입찰 이력으로 별도 판단한다.
- 리브랜딩 자체를 제안서 핵심 변화로 과장하지 않고 추천·진단 기능이 실제 운영 과정에 주는 영향만 설명한다.

## 완료 보고

- 플랫폼별 핵심 변경, 적용 대상·시점, 실무 영향, 공식 링크를 합쳐 5개 항목 이내로 보고한다.
- 중요 변경이 없으면 `중요 신규 업데이트 없음`이라고 짧게 보고한다.
- 공식 공지 접근이 제한되면 변경 없음으로 단정하지 말고 확인하지 못한 경로를 밝힌다.

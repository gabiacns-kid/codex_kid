# 당근 네이티브 광고 - 브랜드 지점 방문 늘리기 목표 (2026-08)

## 문서 성격과 사용 범위

- 기준 자료: `당근 전문가모드 브랜드 지점 방문 늘리기 목표 상품소개서`, 2026.08.
- 확정 범위: 아래 상품 구조와 운영 조건은 제공된 당근 공식 소개서에서 확인한 내용이다.
- 변동 가능성: 입점 요건, 검수 기간, 최소 예산, 타겟·입찰 옵션, 노출 지면은 실제 제안·집행 직전에 당근 전문가모드와 최신 가이드에서 다시 확인한다.
- 광고주 제안 시 성공사례 수치를 일반적인 예상 성과나 보장 수치로 사용하지 않는다.

## 1) 새로 학습한 사실

### 상품 정의

`브랜드 지점 방문 늘리기`는 10개 이상 지점을 보유한 프랜차이즈·다점포 브랜드가 하나의 네이티브 광고 캠페인에서 여러 지점 비즈프로필을 연결하고, 이용자 위치를 기준으로 가까운 지점의 광고와 랜딩을 자동 연결하는 당근 전문가모드 캠페인 목표다.

| 항목 | 소개서 기준 내용 |
|---|---|
| 광고 유형 | 네이티브 광고 |
| 캠페인 목표 | 브랜드 지점 방문 늘리기 |
| 노출 위치 | 당근 앱 홈피드 외 기타 지면 |
| 과금 방식 | CPC |
| 타겟 옵션 | 위치, 모바일, 성별·연령 |
| 소재 | 이미지 + 텍스트 |
| 랜딩 | 이용자 근처 지점의 비즈프로필 홈 또는 브랜드 소식 |
| 운영 대상 | 지점 10개 이상 보유 브랜드 |
| 연결 가능 지점 | 브랜드프로필 하위 최대 3,000개 |

### 본사 중심 다점포 운영 구조

- 본사 통합 광고 계정에서 여러 지점을 하나의 캠페인으로 관리한다.
- 캠페인에 복수 비즈프로필을 연결하며 지점당 광고그룹 1개가 생성된다.
- 이용자의 위치를 기준으로 가까운 지점 광고를 노출하고 해당 지점으로 연결한다.
- 본사가 작성한 브랜드 소식 1개를 선택 지점에 복제하고 원본 수정 내용을 일괄 반영할 수 있다.
- 전체 지점 성과와 지점별 노출·클릭·전환을 통합 대시보드에서 구분해 확인할 수 있다.
- 입찰가와 예산은 전체 지점에 일괄 적용하거나 특정 지점만 개별 적용할 수 있다.
- 집행 중 비즈프로필이 준비된 지점을 추가할 수 있고, 광고그룹 ON/OFF 또는 삭제로 특정 지점 광고를 중단할 수 있다.

### 지역 타겟팅

- 기존 동 단위 또는 원형 반경뿐 아니라 지도상의 실제 도보·자차 이동 거리와 산·강·도로 등 지형을 고려한 지역 타겟팅을 소개한다.
- 따라서 단순 직선 반경보다 실제 생활권·상권·이동 가능 범위를 반영하는 지점 방문형 캠페인에 적합하다.
- 위치 기반 자동 연결이 운영 편의를 높이지만, 지점별 상권·영업시간·재고·프로모션 차이까지 자동으로 최적화해주는 것은 아니다. 본사가 지점별 조건을 별도로 관리해야 한다.

### 랜딩 선택

| 랜딩 | 적합한 상황 | 연결 방식 |
|---|---|---|
| 비즈프로필 홈 | 지점 위치·영업시간·전화 등 매장 기본 정보를 보여줄 때 | 이용자 근처 지점 홈으로 자동 연결 |
| 브랜드 소식 | 전 지점 할인·이벤트·신제품 등 동일 프로모션을 알릴 때 | 이용자 근처 지점의 해당 소식으로 자동 연결 |

- 광고에는 본사가 작성한 브랜드 소식만 사용할 수 있다. 지점 사장님이 작성한 소식은 광고 랜딩으로 사용할 수 없다.
- 원본 브랜드 소식을 수정·삭제·등록하면 연결 지점에 자동 반영된다.

### 입점·등록 조건과 필요 서류

- 지점 10개 미만 브랜드는 해당 목표를 집행할 수 없다.
- 광고 대상 지점마다 비즈프로필이 필요하다.
- 브랜드프로필 입점 필수 서류: 본사 사업자등록증, 재직증명서, 브랜드 프로필 권한 위임 공문.
- 선택 서류: 상표권 등록 증명서, 명함.
- 사업자등록증과 신청 브랜드명이 다르면 브랜드 소유 확인을 위한 상표권 등록 증명서가 필요하다.
- 담당자 이메일이 본사 도메인이 아니면 명함 첨부가 필요하다.

### 예상 준비 일정

1. 브랜드프로필 입점 신청·검수: 영업일 2~3일
2. 지점 일괄 등록·검수: 영업일 3~4일
3. 캠페인 설정·소재 검수: 영업일 1일
4. 소재 검수 완료 후 광고 라이브

집행 지점 수와 서류·비즈프로필 준비 상태에 따라 달라질 수 있으므로 최소 영업일 6~8일 이상의 준비 기간을 두고 희망 시작일에서 역산한다.

### 광고그룹·입찰·예산

- 지점마다 광고그룹 1개가 생성된다.
- 설정 항목: 시간 기준·거리 기준 타겟, 입찰, 일일예산·총예산, 기간·시간대.
- 입찰 방식: 클릭수 최대화 또는 클릭당비용 목표.
- 지점별 개별 입찰가와 예산 설정이 가능하다.
- 광고그룹별 최소 예산은 1만 원이다. 지점 10개 운영 시 캠페인 최소 설정 예산은 10만 원 이상이다.
- 총예산을 사용하는 경우 지점당 일예산 5,000원을 기준으로 최소 설정 금액을 산정한다.

이 최소 금액은 시스템상 설정 가능 금액이지 충분한 성과 판단 예산이 아니다. 실제 예산은 지점 수, 기간, 지역 경쟁도, 목표 클릭수·방문 행동 수를 기준으로 산정해야 한다.

### 소재 운영

- 소재는 지점별 광고그룹에 공통 적용되며 최대 5개까지 생성할 수 있다.
- 기본 생성 단계에서는 전 지점에 동일 소재를 적용하고, 지점별 소재 변경이 필요하면 개별 수정한다.
- 브랜드 소식 랜딩을 사용할 때 광고 사진·제목 수정 옵션을 활용할 수 있다.
- 지역명 변수를 이용해 광고 소재에 이용자 지역을 자동 삽입할 수 있다.

### 성공사례

소개서의 바른치킨 사례는 전월 동일 프로모션 대비 다음 결과를 제시한다.

- 주문 건수: +500%
- 주문 매출액: +60%

단, 절대 주문 수, 광고비, 집행 기간, 대상 지점 수, 프로모션 혜택, 통제군이 제공되지 않았다. 따라서 이 수치는 상품 작동 가능성을 보여주는 단일 사례로만 사용하고 광고주의 예상 성과 산정이나 보장 문구로 사용하지 않는다.

## 2) 기존 지식에서 수정할 점

- 당근 지역 광고를 지점별 개별 캠페인 운영으로만 설명하면 현재 상품 구조를 누락한다. 10개 이상 다점포 브랜드는 본사 통합형 `브랜드 지점 방문 늘리기` 목표를 우선 검토한다.
- 단순 반경 타겟팅으로만 설명하지 않는다. 실제 이동 거리와 지형을 고려한 당근 지역 타겟팅이 소개서에 명시돼 있다.
- 비즈프로필 홈 랜딩만 가능한 것으로 설명하지 않는다. 본사 브랜드 소식과 지점 비즈프로필 홈 중 선택할 수 있다.
- 시스템 최소 예산을 권장 예산으로 혼동하지 않는다. 지점당 최소 설정 금액과 캠페인 학습·성과 판단에 필요한 예산은 별개다.
- `지점 방문 늘리기`라는 명칭만 보고 오프라인 방문이 자동 측정된다고 단정하지 않는다. 소개서에는 지점별 노출·클릭·전환 조회가 언급되지만 전환의 정의와 오프라인 방문 측정 방식은 별도 확인이 필요하다.

## 3) 실무 적용 원칙

### 우선 제안하기 좋은 광고주

- 10개 이상 매장을 가진 프랜차이즈 본사
- 전국 또는 광역 단위 다점포 유통·서비스 브랜드
- 본사가 전 지점 프로모션과 브랜드 소식을 통제하는 구조
- 지점별 비즈프로필, 영업정보, 지역별 예산 관리가 가능한 조직
- 매장 방문·전화·채팅·쿠폰·주문 등 지역 행동을 성과지표로 관리할 수 있는 브랜드

### 제안 우선순위가 낮은 경우

- 지점 수가 10개 미만인 브랜드
- 본사가 지점별 비즈프로필과 매장 정보를 관리할 수 없는 경우
- 지점별 재고·가격·프로모션이 크게 달라 공통 소재가 오해를 만들 수 있는 경우
- 방문 이후 성과를 확인할 전화·쿠폰·주문·POS·CRM 연결 기준이 없는 경우
- 광고 예산이 지점 수 대비 지나치게 작아 광고그룹별 데이터가 분산되는 경우

### 운영 설계

1. 전체 지점을 동일 예산으로 시작하기 전에 핵심 상권·성장 지점·신규 지점·방어 지점 등으로 구분한다.
2. 지점별 상권 규모와 경쟁 강도에 따라 예산·입찰가를 차등 적용한다.
3. 공통 브랜드 소재 2~3개와 프로모션 소재 1~2개로 시작하고 최대 5개를 무조건 채우지 않는다.
4. 비즈프로필 홈 랜딩은 기본 정보·전화·길찾기 목적, 브랜드 소식 랜딩은 기간 한정 혜택·신제품·행사 목적에 사용한다.
5. 소재·랜딩·지점 정보를 동시에 자주 바꾸면 원인 해석이 어려우므로 변경 주기와 변경 이력을 관리한다.
6. 지점별 노출·클릭뿐 아니라 전화, 채팅, 길찾기, 쿠폰, 주문, POS 매출 등 실제 사업지표와 비교한다.
7. 상단·하단 성과 지점을 나눈 뒤 예산 재배분, 지역 범위 조정, 입찰가 조정, 매장정보 보완을 각각 구분해 실행한다.

### 제안 전 필수 확인

- 정확한 운영 지점 수와 광고 대상 지점 수
- 브랜드프로필 입점 여부 및 본사 권한
- 지점별 비즈프로필 생성·정보 최신화 여부
- 전 지점 공통 프로모션 가능 여부
- 지점별 영업시간·가격·재고·서비스 차이
- 지점 방문 또는 매장 행동을 판단할 전환 정의
- 지역별 광고 예산과 지점별 손익 기준
- 최신 전문가모드에서 제공되는 보고서 항목과 전환 정의

## 4) 제안서/리포트 문장 예시

### 제안 문장

> 10개 이상 지점을 운영하는 브랜드는 지점마다 캠페인을 따로 만드는 대신, 당근 전문가모드의 ‘브랜드 지점 방문 늘리기’ 목표를 통해 하나의 캠페인에서 여러 지점을 관리할 수 있습니다. 이용자의 위치를 기준으로 가까운 지점의 비즈프로필 또는 프로모션 소식으로 자동 연결하고, 지점별 예산과 입찰가를 조정해 지역별 성과 차이까지 관리하는 방식입니다.

> 초기에는 전 지점에 동일 예산을 나누기보다 핵심 상권과 우선 육성 지점을 구분해 집행합니다. 지점별 노출·클릭과 함께 전화·채팅·길찾기·쿠폰·주문 등 실제 매장 행동을 비교한 뒤 성과가 확인된 지역에 예산을 재배분하겠습니다.

### 리포트 문장

> 전체 캠페인 클릭률은 안정적이었으나 지점별 편차가 크게 나타났습니다. 다음 기간에는 상위 지점의 지역 범위와 소재 반응을 기준으로 유사 상권에 예산을 확대하고, 하위 지점은 입찰가를 높이기 전에 비즈프로필 정보와 영업 조건, 랜딩 소식의 적합성을 먼저 점검하겠습니다.

> 프로모션 소식 랜딩은 클릭을 확보했지만 매장 행동 데이터가 부족해 방문 효과를 확정하기 어렵습니다. 다음 보고부터 지점별 전화·채팅·길찾기·쿠폰·주문 지표를 함께 비교하여 단순 클릭과 실제 방문 의도를 구분하겠습니다.

## 5) 다음 확인 필요사항

- `전환`으로 집계되는 행동의 정확한 정의와 지점 방문 측정 지원 여부
- 홈피드 외 세부 노출 지면과 지면별 성과 확인 가능 범위
- 모바일 타겟팅의 세부 설정 항목

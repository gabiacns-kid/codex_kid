# 산업안전용품 검색·쇼핑광고 운영 기준

## 2026-10-20 학습 요약

### 1) 새로 학습한 사실

- 산업안전용품 전문몰은 `고가·현장설계형 스마트 안전장비`와 `규격형 개인안전보호구`가 한 사이트에 함께 판매될 수 있다.
- 이동형 CCTV, 중장비 접근 감지기, 스마트 에어백, 현장 센서처럼 사양·설치·견적 확인이 필요한 제품은 상품가격만 비교하는 쇼핑검색보다 파워링크의 상담·견적 랜딩이 우선이다.
- 안전화, 안전장화, 안전벨트, 안전모, 안전조끼, 각반처럼 브랜드·모델·규격이 명확한 제품은 쇼핑검색광고와 잘 맞는다.
- 쇼핑검색광고 쇼핑몰 상품형은 키워드를 직접 등록하지 않고 상품명, 카테고리, 속성 등 상품정보를 기반으로 검색어가 자동 매칭된다. 따라서 `쇼핑 키워드 리스트`는 등록 목록이 아니라 상품정보 정비와 노출 검색어 점검 기준으로 사용해야 한다.

공식 확인:

- 네이버 광고주센터 `쇼핑검색광고 검색 매체와 노출 방식이 궁금해요.`, 확인일 2026-10-20: https://ads.naver.com/help/faq/1196
- 네이버 광고주센터 `카테고리 매칭은 어떻게 하나요?`, 확인일 2026-10-20: https://ads.naver.com/help/faq/876

### 2) 기존 지식에서 수정할 점

- 산업안전용품이라는 공통 카테고리만으로 모든 품목을 한 캠페인에 묶지 않는다. 구매형과 상담형의 전환 경로가 다르다.
- 쇼핑검색광고 제안서에서 키워드 등록·입찰 구조처럼 설명하지 않는다. 상품그룹, 상품정보, 카테고리, 입찰가, 제외검색어 운영으로 설명한다.
- 고가 스마트 장비가 사이트에서 결제 가능하더라도 결제 가능하다는 이유만으로 쇼핑광고 우선 상품으로 판단하지 않는다. 실제 구매에 현장 조건과 견적 상담이 필요한지 확인한다.

### 3) 실무 적용 원칙

1. 파워링크는 `스마트 안전장비·견적`, `CCTV·바디캠`, `중장비 위험감지`, `환경계측`, `산업안전용품몰`로 그룹화한다.
2. 쇼핑검색은 `안전화`, `안전장화`, `안전벨트`, `안전모`, `안전조끼`, `각반`, `소형 안전용품`을 상품그룹으로 분리한다.
3. 브랜드와 모델이 있는 PPE 상품은 상품명에 `브랜드 + 품목 + 모델 + 핵심 규격`을 정확히 반영한다.
4. 쇼핑 노출 검색어는 등록 전 후보 목록과 집행 후 실제 검색어 보고서를 비교하고, 무관 검색어는 제외검색어로 관리한다.
5. 파워링크에는 DIAD Pro를 적용해 PC·모바일 순위, 최대 입찰가, 입찰 이력과 CPC를 관리하되 문의·구매를 보장하는 도구로 표현하지 않는다.

### 4) 제안서 문장 예시

> 고가 스마트 안전장비는 현장 조건과 사양 확인이 필요하므로 파워링크에서 견적·상담 수요를 확보합니다. 브랜드와 규격이 명확한 안전화·안전벨트 등은 쇼핑검색광고로 상품 비교 단계의 수요를 확보하겠습니다.

> 쇼핑검색광고는 키워드를 직접 등록하는 방식이 아닙니다. 상품명·카테고리·속성을 기준으로 검색어가 자동 매칭되므로 상품군별 그룹 운영과 실제 노출 검색어 점검을 중심으로 관리하겠습니다.

### 5) 다음 확인 필요사항

- 네이버쇼핑 입점·상품 연동 여부
- 상품별 카테고리, 브랜드, 모델, 규격 속성 등록 상태
- 고가 장비의 온라인 결제와 견적 상담 비중
- 상품별 목표 ROAS와 허용 광고비
- 실제 노출 검색어와 제외검색어 운영 현황

# 모비온·타게팅게이츠 네트워크 광고 판단 가이드

## 적용 범위

모비온 또는 타게팅게이츠를 자사몰 유입, 리타겟팅, 상품 피드, 신규 고객 탐색, DB 수집 매체로 검토할 때 사용한다. 상품소개서 수치를 그대로 성과 예측치로 옮기지 말고 광고주의 예산, 사이트 방문 모수, 전환 태그, 상품 피드, 소재 제작 여력, 기존 Google·Kakao·Meta 집행과의 중복을 먼저 확인한다.

## 근거와 최신성

- 모비온 상품소개서: 48쪽, PDF 메타데이터상 2024-01-31 제작. 상품 구성과 당시 운영 조건을 보여주는 매체사 자료다.
- 모비온 사용자 설정 가이드: 14쪽, PDF 메타데이터상 2022-11-16 제작. 현재 UI를 확정하는 자료로 사용하지 않는다.
- 타게팅게이츠 `2026 Artist-Company 통합상품 소개서 v3.4`: 27쪽, PDF 메타데이터상 2026-07-24 제작.
- 아티스트컴퍼니 공식 홈페이지는 타게팅게이츠의 리타겟팅·유저 타겟팅과 검색·방문·콘텐츠 행동 기반 데이터 활용을 현재도 소개한다. 세부 단가·최소 집행액·데이터 보유량은 제안 직전에 담당자 또는 최신 상품소개서로 다시 확인한다.

## 2026-09-03 변경 요약

### 1) 새로 학습한 사실

- 제공 자료 기준 모비온은 고정·상품화·리뷰·동영상 배너와 행동 기반 리타겟팅, Tune720 세그먼트를 함께 제시한다. 모비온 소개서의 신규 첫 집행 최소 충전액 100만원과 평균 CPC 예시는 2024년 자료다.
- 2026년 타게팅게이츠 소개서는 리타겟팅, RFM, DMP, 최근 14일 검색 관심, 브랜드 인게이지먼트, 다이나믹·동영상 배너 등을 제시한다. 일반 캠페인의 최소 집행액과 평균 CPC는 자료에서 확정할 수 없다.
- 두 매체 모두 검색광고를 대체하기보다 검색·발견 이후의 재접촉과 관심 지속, 또는 별도 신규 타겟 검증에 활용하는 편이 적합하다.

### 2) 기존 지식에서 수정할 점

- 두 매체 모두 최소 집행액이 100만원이라고 확정하지 않는다. 모비온은 오래된 자료의 당시 조건이고, 타게팅게이츠는 최신 견적 확인이 필요하다.
- 저렴한 CPC, 넓은 지면, 높은 커버리지만으로 자사몰 활성화 효과를 확정하지 않는다. 방문 품질과 상품조회·장바구니·구매의 증분을 확인한다.
- Google GDN·Kakao·Meta와 함께 여러 네트워크를 소액으로 동시 운영하지 않는다. 중복 도달과 학습량 부족이 생길 수 있다.

### 3) 실무 적용 원칙

1. 검색·발견 매체가 만든 방문자를 다시 환기할 목적이라면 최근 방문 모수와 상품별 이벤트 수집 상태를 먼저 확인한다.
2. 초기에는 모비온 또는 타게팅게이츠 한 개만 선택해 월 100만원 안팎의 제한 테스트를 하고 GA4와 매체 보고서를 병기한다.
3. 상품 피드와 행동 데이터가 충분하면 다이나믹 리타겟팅을, 모수가 작으면 검색 관심·카테고리 DMP 같은 신규 타겟을 별도 그룹으로 시험한다.
4. 아이커버처럼 포맷 특성상 클릭이 강제되거나 확대되는 상품은 일반 배너 CTR과 직접 비교하지 않고 체류·상품조회·구매까지 본다.

### 4) 제안서/리포트 문장 예시

> 네트워크 광고는 검색광고의 대체재가 아니라, 이미 상품을 보거나 관련 수요를 탐색한 고객에게 다시 브랜드를 환기하는 보조 채널로 운영합니다. 초기에는 한 개 매체만 제한적으로 테스트하고, 단순 유입량보다 상품조회·장바구니·구매까지 이어지는 방문 품질을 기준으로 확대 여부를 판단합니다.

### 5) 다음 확인 필요사항

- 집행 시점의 최소 예산, 단가, 수수료와 계약 기간
- 실제 제공 지면, 앱·웹 비중, 빈도 제한과 지면 제외 범위
- 리타겟팅 최소 모수, 데이터 보유 기간, 검색어·DMP 타겟의 가용 모수
- 전용 스크립트·상품 피드·전환 이벤트와 중복 귀속 규칙

## 모비온 상품 구조

### 외부 광고

| 상품/방식 | 자료상 특징 | 적용 판단 |
|---|---|---|
| 고정배너 | 언론사·커뮤니티·포털·RTB·앱에 이미지 배너 노출, CPC 과금 | 신규 수요 탐색 또는 리타겟팅. 폭넓은 사이즈 제작 부담과 지면 품질 관리가 필요하다. |
| 상품화배너 | 방문·상품조회 등 행동을 바탕으로 상품 이미지를 자동 구성하는 다이나믹 피드형 배너 | 상품 수, 피드 품질, 스크립트, 상품별 랜딩, 충분한 행동 데이터가 있을 때 우선 검토한다. |

| 아이커버 | 제휴 매체 접속 또는 뒤로가기 시 광고주 페이지를 직접 여는 방식 | 저단가 유입 확대에는 사용할 수 있으나 강제성·사용자 경험·이탈률을 별도로 평가한다. 자료의 CTR 100%는 포맷 구조에서 발생하므로 일반 클릭 성과와 비교하지 않는다. |
| 모비온×카카오 | 모비온 타겟팅을 접목한 카카오 비즈보드 운영 | 카카오모먼트 직접 집행과 별도 신규 지면처럼 중복 계산하지 않는다. 대행 구조, 데이터 결합 범위, 성과 귀속을 확인한다. |
| 동영상 배너 | 네트워크 배너 구좌에서 15초 이내 영상 자동재생, CPC 과금 | 숏폼 자체 조회보다 사이트 유입을 목표로 할 때 검토한다. 사이즈별 영상 제작과 실제 재생·가시성 지표를 확인한다. |

### 사이트 내부 솔루션과 데이터

- 인사이트 마케팅은 사이트 메인·이탈 구간의 팝업 또는 상품상세 추천 패널로 체류와 전환을 보완하는 온사이트 기능이다. 외부 광고 도달 상품과 구분한다.
- Tune720은 스크립트로 수집한 사이트 내부 행동, RFM, 상품·광고 효과와 외부 활동 데이터를 결합해 세그먼트와 캠페인을 만드는 진단/활용 플랫폼으로 소개된다.
- 캠페인 목적은 브랜딩·전환 최적화·잠재고객 확보·앱 캠페인으로 제시된다. 상담/신청은 잠재고객 확보 캠페인으로 설계할 수 있지만 전환 이벤트 정의와 중복·허수 DB 검증이 선행되어야 한다.

### 소개서에 기재된 당시 조건

- 고정배너와 상품화배너의 평균 CPC 예시는 250원, 신규 첫 집행 최소 충전액은 100만원(VAT 별도)이다.
- 리뷰배너 평균 CPC 예시는 300원이다.
- 스마트스토어는 방문·상품조회 리타겟팅만 가능하고 장바구니·전환 리타겟팅은 제한된다고 기재되어 있다.
- 자사몰이나 스마트스토어 없이 블로그·인스타그램으로 랜딩할 수는 있지만 스크립트 기반 전환 추적과 리타겟팅은 불가하다고 설명한다.
- 지역 타겟팅은 특별시·광역시·도 단위로 기재되어 있으며, 배너 사이즈별 성과는 제공하지 않는다고 설명한다.
- 위 단가와 조건은 2024년 자료이므로 현재 제안서의 확정 조건으로 쓰기 전에 재확인한다.

### 노출 형식과 스마트스토어 패키지

- 고정·반응형·다이나믹·동영상·카운트다운·룰렛 배너를 타겟팅과 조합할 수 있다고 소개한다.
- 스마트스토어 패키지는 업종 세그먼트, 아이커버, 광고 클릭 모수, 모바일 페이 이용 유저를 활용한다고 설명한다.
- 스마트스토어 패키지의 기존 광고 클릭 모수 활용에는 `TG 1천만원 이상 집행 이력`이 필요하다고 기재되어 있다. 신규 또는 소액 테스트 광고주에게 기본 제공되는 기능처럼 제안하지 않는다.
- 소개서에는 일반 캠페인의 최소 집행액과 평균 CPC가 명시되지 않았다. 견적 전에 확인한다.

## 제안 판단 원칙

1. 네트워크 광고는 검색광고를 대체하는 수요 포착 매체가 아니다. 검색에서 확인된 관심을 재접촉하거나, 이미지·상품 피드로 검색 이전 수요를 넓히는 역할로 정의한다.
2. 월 예산이 작으면 Google GDN/Demand Gen, Kakao display, Meta, 모비온, 타게팅게이츠를 동시에 나누지 않는다. 도달 중복과 학습량 부족을 피하기 위해 한 개 네트워크를 제한 테스트한다.
3. 리타겟팅이 목적이면 최근 30일 방문자와 주요 상품조회자 규모를 먼저 확인한다. 모수가 작으면 신규 타겟과 혼합하되 성과를 분리한다.
4. 자사몰은 스크립트, 상품 피드, `view_item/add_to_cart/purchase` 또는 상담 이벤트, 동적 랜딩 파라미터, 중복제거 기준을 확인한다. 픽셀 설치만으로 상품별 전환 최적화가 보장된다고 쓰지 않는다.
5. 네트워크 매체 대시보드의 세션·직접·총 전환기간과 GA4의 세션·기여 방식은 다를 수 있다. 동일 ROAS처럼 합치지 말고 매체 기준과 GA4 기준을 병기한다.
6. 매체사가 제시한 KPI 달성률, 계약연장률, 커버리지, CPC, ROAS, CPA 사례는 매체사 자료의 예시다. 광고주 예측치나 보장치로 사용하지 않는다.
7. 지면 전체 목록이 공개되지 않거나 제외 내역 확인이 제한될 수 있으므로 앱·매체 유형·게재 위치·브랜드 세이프티·무효 트래픽 대응·제외 가능 범위를 계약 전에 확인한다.

## 조지루시 적용 메모

- 조지루시는 자사몰 활성화가 목적이고 네이버 쇼핑·스마트스토어 운영 의사가 없으므로 네트워크 광고의 랜딩은 공식몰 상품상세로 통일한다.
- 월 파워링크 예산 상한이 200만원 수준이라면 네트워크 광고를 동시에 크게 나누면 검색 수요 포착이 약해질 수 있다. 별도 증액 예산 또는 파워링크 성과가 안정된 뒤 월 100만원 안팎의 단일 매체 테스트가 현실적이다.
- 모비온은 2024년 자료상 신규 최소 100만원이므로 실제 현재 최소액을 확인한다. 타게팅게이츠는 2026년 소개서에 최소액이 없어 별도 견적이 필요하다.
- 1차 후보는 가열식 가습기·텀블러·보온도시락·오븐레인지 상품조회자 리타겟팅이다. 계절성과 방문 모수가 충분하면 상품화/다이나믹 배너를 사용하고, 모수가 작으면 검색어 기반 관심 타겟 또는 카테고리 DMP를 소액으로 비교한다.
- 소재는 제품 사진만 나열하지 말고 `세척 편의`, `보온·보냉`, `용량`, `사용 상황`, `공식몰 혜택` 중 상품별 한 가지 이유를 앞세운다. 경쟁사명 타겟팅은 가능 여부와 상표·소재 정책을 확인하고 광고 문구에는 오인 표현을 쓰지 않는다.
- 아이커버는 자사몰 유입 수를 빠르게 늘릴 수 있으나 방문 의도가 약할 수 있어 첫 테스트의 주력으로 두지 않는다. 체류, 상품조회, 장바구니, 구매까지 비교할 수 있을 때 보조군으로만 시험한다.
- Google·Kakao 리타겟팅을 이미 운영한다면 같은 방문자에게 중복 노출될 가능성이 높다. 한 매체씩 테스트하거나 예산·기간·빈도를 분리해 증분 효과를 확인한다.

## 제안 전 확인 목록

- 현재 최소 집행액, VAT·수수료·정산 기준, 계약 기간
- 현재 제공 가능한 지면과 앱/웹 비중, 주요 매체 목록, 지면 제외 방식
- CPC/CPM/CPV 등 과금 방식과 입찰·빈도·예산 상한 설정
- 자사몰 스크립트·상품 피드·동적 배너 규격·개발 소요기간
- 리타겟팅 최소 모수와 보유 기간, 검색어/DMP 타겟의 실제 가용 모수
- 전환 인정 기간, 직접·간접 전환 정의, 중복 전환 제거, GA4와의 비교 방법
- 브랜드 세이프티, 무효 트래픽, 개인정보·동의, 소재 심사 정책

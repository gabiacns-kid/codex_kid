# B2B 기업인증·조달·ISO 컨설팅 검색광고

## 적용 원칙

- 기업인증 컨설팅은 `기업인증` 같은 넓은 키워드 하나로 묶지 않는다. ISO 시스템 인증, 조달등록, 제품인증, 환경인증, 기업인증, 식품·화장품 인증으로 그룹을 나눈다.
- 서비스명 단독 키워드보다 `인증`, `등록`, `대행`, `컨설팅`, `비용`, `절차`가 결합된 검색어에서 상담 의도를 구분한다.
- `ISO`, `FDA`, `CE`, `HACCP`처럼 정보 탐색과 교육 수요가 큰 키워드는 단독 고가 입찰을 피하고 인증 취득·견적 의도가 있는 조합부터 운영한다.
- 광고그룹은 인증 종류별로 나누고 각 그룹의 제목·설명·랜딩을 해당 인증 상세페이지와 연결한다. 여러 인증을 한 페이지로 보내지 않는다.
- 실제 등록 전 네이버 키워드도구에서 월간 검색수, 예상 클릭, 입찰가와 경쟁도를 확인한다. 사이트 적합도와 검색량은 같은 개념이 아니다.
- 상담 KPI는 문의 수만 보지 않고 인증 종류, 신청 목적, 예상 일정, 기업 규모, 현재 준비 상태를 함께 확인한다.

## 한국경영연구소 사이트에서 확인된 주요 서비스군

- ISO: ISO 9001, 14001, 45001, 13485, 22716, FSSC 22000, 50001, 37001, 37301, 27001, 27701, 42001
- 조달: 우수조달제품, 다수공급자계약(MAS), 품질보증조달물품, 벤처나라, 혁신시제품
- 제품: KS, 단체표준, NEP, 성능인증, K마크, Q마크, 친환경건축자재, 고효율에너지기자재, CE, FDA
- 환경: 환경성적표지, 저탄소인증, 환경표지, GRS, ISCC PLUS, FSC
- 기업: 서비스품질우수기업, 이노비즈, 메인비즈, 벤처기업, 기업부설연구소
- 식품·화장품: HACCP, HALAL, VEGAN, Gluten Free, Non-GMO, FDA

## 제안서 문장 예시

> 기업인증 검색은 인증 종류마다 신청 목적과 준비 서류가 다릅니다. ISO·조달·제품·환경·기업 인증을 각각 별도 광고그룹으로 나누고, 검색한 인증의 상세 안내와 견적문의 페이지를 바로 연결해 상담 이탈을 줄이겠습니다.

## 확인 필요사항

- 인증별 실제 매출 기여도와 우선 수주 분야
- 지역 제한, 지원사업 연계 여부, 수행 가능 업종
- 인증기관·컨설팅기관·교육기관 역할의 구분과 광고 표현
- 인증별 평균 상담 기간, 수주 가능성이 높은 문의 조건
- 네이버 키워드도구 기준 검색량·입찰가·경쟁도

# Google·Meta 공식 광고 업데이트 모니터링

Google Ads와 Meta Ads의 공식 변경을 광고 제안·운영 판단에 사용할 수 있는 도메인 지식으로 누적할 때 사용한다.

## 확인 범위

- 직전 성공 점검 이후 새로 게시되거나 실질적으로 변경된 내용만 확인한다. 최초 점검은 최근 14일을 기준으로 한다.
- Google은 Google Ads 고객센터·광고 정책·Ads & Commerce 공식 소식·Google Ads Editor 새 소식을 우선한다. GA4와 Merchant Center는 광고 측정·쇼핑 집행에 직접 영향을 줄 때만 포함한다.
- Meta는 광고 지원 허브·Meta for Business 공식 소식·광고 표준·광고 제품 및 Audience Network 공식 업데이트를 우선한다.
- 제3자 자료는 후보 탐색에만 사용할 수 있으며, 공식 원문으로 확인되지 않은 내용은 확정 변경으로 저장하지 않는다.

## 판단 규칙

1. 발표일과 적용일을 분리한다.
2. 순차 제공·베타·테스트·일부 계정·특정 국가·특정 업종을 전체 제공처럼 표현하지 않는다.
3. 단순 UI 변경, 퍼블리셔 전용 변경, 광고주 영향이 미미한 소식은 제외한다.
4. 집행·입찰·측정·소재·정책·보고 정의 중 무엇이 달라지는지 밝힌다.
5. 운영 영향은 확인된 사실과 추론을 구분한다. 계정 데이터가 없으면 실제 성과 변화로 단정하지 않는다.
6. 같은 내용을 다시 보고하지 않는다.
7. 공식 원문 접근이 막히면 `중요 신규 업데이트 없음`으로 단정하지 말고, 확인 범위와 제한을 함께 적는다.

## 도메인 지식 반영

- Google의 유의미한 변경은 `google-ads-help-decision-framework-202608.md`에 날짜, 적용 범위, 실무 원칙, 공식 링크를 추가한다.
- Meta의 유의미한 변경은 `meta-ads-help-decision-framework-202608.md`에 같은 구조로 추가한다.
- 새 내용이 없으면 플랫폼 레퍼런스를 수정하지 않는다.
- 설치된 동일 스킬 사본이 별도 경로에 있으면 원본과 동기화하되, 쓰기 권한이 없을 때는 우회하지 않고 미동기화 상태를 보고한다.

## 광고컨설팅 작업 전달

- 사용자가 지정한 누적 작업은 현재 `광고컨설팅(3)`이다. 작업 목록에서 제목을 정확히 확인한 뒤, 확인된 신규 변경과 실무 적용 원칙을 해당 작업에 전달한다.
- 전달 내용은 플랫폼별 핵심 변경, 적용 대상·시점, 제안서/운영상 영향, 공식 링크를 합쳐 5개 항목 이내로 작성한다.
- 변경이 없으면 짧게 보고한다. 검증 제한이 있으면 제한을 숨기지 않는다.
- 해당 작업에 메시지를 보내는 것은 사용자 또는 자동화가 명시적으로 허용한 경우에만 수행한다.

# Blog Image Production Reference

Use this reference when creating or critiquing blog post image scripts, 1:1 card-news visuals, HTML/CSS-renderable image mockups, or marketing infographic images for GabiaCNS-style blog content.

## Core Purpose

Blog images should not be decorative filler. They should:

- summarize a section of the article,
- help the reader understand the content faster,
- create a visual pause while keeping the article's professional tone,
- make the post look planned rather than auto-generated.

## Preferred Direction

- Use a professional marketing-report style.
- Prioritize stable layout, readable typography, and clear information hierarchy.
- Prefer 1:1 square formats for blog/card-news use unless the user asks otherwise.
- Use Pretendard when possible. Paperlogy can be considered, but Pretendard is the safer default for ad/marketing explainers.
- Use icons sparingly and consistently. Icons should support comprehension, not make the image look childish.
- Use cards, tables, checklists, comparison blocks, scenario blocks, and concise conclusion boxes.

## Layout Patterns

### Main Thumbnail

Use for the first image of the post.

- Large title.
- Short subtitle or category label.
- 2-3 supporting keywords or chips.
- Strong center or left-aligned composition.
- Enough visual weight so the image does not look empty.

### Comparison Image

Use after sections comparing two models, media, channels, or strategies.

- Two cards or columns.
- Clear headings for both sides.
- Short differences, not long paragraphs.
- Use color contrast to separate the two sides.
- Add one conclusion line at the bottom if it fits.

### Scenario Image

Use for attribution, customer journey, campaign examples, or before/after logic.

- Use CASE blocks.
- Show the flow visually.
- Keep result metrics aligned in columns.
- Avoid cramming too many steps into one line.

### Checklist Image

Use near conclusions or practical guidance sections.

- 4-5 checklist items.
- Left check icon, right concise sentence.
- Same vertical spacing across items.
- Avoid overly large check icons.

### Strategy Summary Image

Use for budget, media mix, or action-plan sections.

- Top headline.
- Middle 3 cards or 3 rows.
- Bottom takeaway message.
- The bottom message box must have enough vertical height and padding so text never touches the border.

## Common Problems to Avoid

- The image looks too empty because there are too few text blocks or too much unused background.
- The image looks AI-generated because of childish icons, random decorative shapes, or overdone gradients.
- Text overflows outside cards.
- Text and boxes feel disconnected because vertical alignment and padding are inconsistent.
- Bottom conclusion boxes have text that is not vertically centered.
- Three-card layouts use fonts that are too large for the card width.
- Progress bars, gauge bars, or decorative data elements appear without meaningful data.
- Background patterns compete with the text.

## Text Sizing Guidance

For 640-700px square images:

- Main title: roughly 34-48px depending on line count.
- Section title: roughly 26-34px.
- Card title: roughly 17-22px.
- Card body: roughly 12-16px.
- Captions/labels: roughly 10-13px.

Adjust down for long Korean words. Never let the longest word escape its container.

## Tone

Aim for:

- polished,
- practical,
- report-like,
- readable at mobile size,
- understated but not empty.

Avoid:

- overly playful,
- generic AI poster,
- stock-template feeling,
- decorative dashboard without content,
- icon-heavy children's worksheet feeling.

## User Preference From Prior Iteration

The user preferred the most stable first example layout over more experimental variants. When revising image scripts:

- Preserve the stable structure first.
- Improve font, alignment, spacing, and content density.
- Do not change the entire visual concept unless the user asks.
- Remove nonessential elements like lower gauge bars when they cause clutter or weak meaning.

# 2027 소비 트렌드 참고 기준 — 와이즈앱 웨비나 자료

## 자료 범위와 해석 주의

- 출처: 사용자가 제공한 `261022_와이즈앱 웨비나_2027 소비 10대 트렌드.pptx` (2026-10-22).
- 자료는 `TREND KOREA 2027 | ALPHA SHEEP`의 10개 키워드를 와이즈앱 웨비나 관점에서 정리한 발표 자료다.
- 트렌드 키워드는 소비자 해석과 제안 방향을 보완하는 참고 프레임으로 사용한다. 시장 규모, 구매 의도, 광고 성과를 증명하는 데이터로 단독 사용하지 않는다.
- 제안서에 반영할 때는 해당 업종의 실제 상품·고객·검색수요·광고 데이터와 연결되는 항목만 선택한다. 유행어를 나열하거나 모든 업종에 동일하게 적용하지 않는다.

## 10개 키워드와 광고 제안 활용 범위

1. **권태사회**: 과도한 자극에 지친 소비자를 전제로, 과장된 훅보다 짧고 명확한 효용·사용 장면·새로운 경험을 보여줄 때 참고한다.
2. **라이프 ROI**: 시간·노력 대비 보상을 따지는 소비 성향. 구독, 교육, 여행, 생활서비스, 건강관리 업종에서 시간 절감과 선택 편의성을 구체적으로 설명한다.
3. **폼팩터 시프트**: 핵심 기능을 유지하며 형태와 사용 방식을 바꾸는 흐름. 가전·생활용품·뷰티·식품에서 휴대성, 공간 효율, 사용 편의, 새로운 패키지 구성을 소재화할 때 활용한다.
4. **해봄경제**: 완벽한 준비보다 빠른 실행과 경험을 중시하는 흐름. 체험형 상품, 클래스, DIY, 신제품 테스트, 샘플·입문형 구성의 진입 장벽을 낮추는 제안에 활용한다.
5. **저장인류**: 일상 기록을 축적하고 다시 활용하는 성향. 사진·영상·여행·육아·반려동물·생산성 도구에서 기록, 정리, 회고, 재활용 경험을 연결한다.
6. **바이브 워킹**: 사람과 AI가 한 업무 흐름에서 협업하는 방식. B2B SaaS, 업무도구, 교육, 전문서비스 제안에서 단순 AI 보유보다 실제 업무 단계와 연결되는 효율을 설명한다.
7. **리:텐션 전략**: 신규 고객 획득 중심에서 기존 고객이 다시 찾고 오래 머무를 이유를 만드는 방향. 반복구매 상품, 구독, 멤버십, CRM이 있는 업종에서 재구매·재방문 설계를 제안할 때 활용한다.
8. **휴먼엣지**: AI 결과물의 범용화 속에서 사람의 경험·선택·손길·시간·책임이 차별화 요소가 되는 흐름. 전문서비스, 수공예, 의료·교육 상담, 로컬 브랜드에서 담당자 전문성과 제작·검수 과정을 강조한다.
9. **하프시그널**: 갱년기를 쇠퇴가 아닌 생애 전환 신호로 바라보는 관점. 건강·뷰티·여행·금융·교육에서 중년 고객을 결핍이나 노화만으로 묘사하지 않고, 자기관리와 다음 단계 준비 관점으로 표현한다.
10. **안목자본**: 취향과 진위를 판별하는 능력이 경제·사회적 자본이 되는 흐름. 패션·인테리어·식음료·문화·프리미엄 소비재에서 큐레이션 근거, 선택 기준, 브랜드 철학을 구체적으로 제시한다.

## 실무 적용 원칙

- 트렌드는 제안의 출발점이 아니라 보조 설명이다. 검색량, 고객 데이터, 상품 경쟁력, 판매 구조와 맞지 않으면 사용하지 않는다.
- 한 제안서에는 직접 연결되는 키워드 1~2개만 사용하고, 상품 기능·고객 문제·광고 소재·랜딩페이지 중 어디에 반영할지 명시한다.
- `리:텐션 전략`은 CRM·재구매 데이터가 확인될 때만 운영안으로 확장한다. 광고 데이터만으로 고객 생애가치나 유지율을 안다고 표현하지 않는다.
- `바이브 워킹`과 `휴먼엣지`는 상반된 주장이 아니다. 반복 작업은 AI로 줄이고, 판단·책임·경험은 사람이 제공한다는 역할 구분으로 설명한다.
- 발표 자료의 사례와 수치는 제공 파일 기반 참고사항이다. 외부 제안서에서 정량 근거로 쓸 때는 원출처와 최신성을 별도로 확인한다.

# Government Advertising Q&A Preparation

Use this reference when preparing expected interview questions and answers for Korean government advertising RFP presentations.

## Core Stance

Expected Q&A should not simply repeat slide headlines. It should defend the proposal's operating logic against the questions evaluators usually ask:

- Is the KPI calculation realistic?
- Is the solution real, owned, partnered, or only a concept?
- Can automated bidding actually prevent over-spend?
- How are many keywords reviewed without wasting budget?
- How does the staffing model work in practice?
- Can public-sector objectives be handled when the references include commerce cases?
- What is guaranteed, and what is only a case-based improvement direction?

## Question Selection Priority

Start from actual previous questions before inventing new ones. High-probability patterns include:

1. KPI basis and whether the proposed CPC/click target can be achieved.
2. Media-mix rationale, especially why Naver is the main medium and Kakao/Google are supplementary.
3. Tool reality: Ads Studio, trend analysis, DIAD Pro, MOP, and whether each is in-house or partner-based.
4. Automation limits: automatic bidding is useful for rank/CPC control, but not a conversion guarantee.
5. Keyword expansion risk: expanded terms must be filtered, excluded, and converted to directly managed keywords when performance is proven.
6. Reporting: explain what decisions the report enables, not only what metrics are delivered.
7. SEO-SEM connection: if the institution site cannot be edited, explain ad-side alternatives and separate SEO recommendations.
8. A/B testing scope: include keyword groups, rank, media product, landing page, and creative, not only copy.
9. Staffing: distinguish role-based TFT coverage from every person being full-time on every campaign.
10. References: explain how public-sector and commerce cases are relevant at the method level, while not overclaiming identical outcomes.

## Answering Rules

- Avoid guarantee language unless it is explicitly contractually required.
- If a number is from a case, call it a case-based reference, not a universal promise.
- If a solution is not owned by GabiaCNS, say so plainly and position GabiaCNS's role as operation design, integration, and judgment.
- Link every answer to the RFP's two-level KPI structure: total KPI management and media/campaign-level operating KPI.
- Use "official information delivery" and "public access to accurate policy information" as the public-sector frame.
- For MOP, say it is most meaningful when there is enough budget/history/data. For data-poor campaigns, start with keyword structure, bidding, and reporting.
- For Power Content or blog landing, frame it as an information-stage bridge, not as a replacement for official-page traffic.
- Keep the answer concise enough for spoken delivery, but include a practical operating action.

## Workbook Shape

When producing an Excel Q&A draft, keep the original requested columns if supplied:

- no
- page number
- category
- question
- answer
- person in charge

If the actual responsible names are unknown, temporarily fill the person column with role labels such as PM, operation, solution, design, or finance, and tell the user to replace them before submission.

For review convenience, add a summary sheet with the same Q&A rows and an optional priority column. Do not overpopulate with low-probability questions; 25 to 35 high-priority items are usually more useful than 60 generic questions.

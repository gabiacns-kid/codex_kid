# ChatGPT Ads 대한민국 대행사 운영 기준

확인일: 2026-09-17

이 문서는 대한민국 광고주에게 ChatGPT Ads를 제안하거나 대행 운영할 때 사용한다. 현재 상품은 `Ads Manager Beta`이므로 기능·정책·과금·타겟팅은 제안 직전에 공식 도움말과 실제 계정에서 다시 확인한다.

## 1. 현재 확인된 운영 구조

- 대한민국 소재 법인은 Ads Manager 셀프서비스 이용 가능 국가에 포함된다.
- 각 광고주는 별도 광고계정을 만들어야 한다. 계정 소유자가 대행사 담당자를 사용자로 초대하며, 역할은 광고 계정 관리자·멤버·뷰어 등으로 구분한다.
- 광고계정 생성 시 국가, 통화, 시간대를 정하며 이후 직접 변경할 수 없다. 광고주 법인과 결제 주체를 먼저 확정한다.
- 가입 후 비즈니스 정보, 웹사이트, 로고, 업종을 입력하고 Persona 인증 및 OpenAI 계정 심사를 거친다. 인증 완료만으로 즉시 게재되는 것은 아니다.
- 결제는 선불 충전이 아니라 카드 후불 청구다. 계정별 결제 기준액 도달 시 또는 월말에 청구된다. 결제 기준액은 캠페인 예산이나 계정 지출 한도가 아니다.
- 대한민국 원화 계정의 최소 일일 예산은 25,000원이다.

## 2. 광고 노출과 사용자 범위

- 광고는 ChatGPT 답변 아래 별도의 스폰서 광고로 표시되며 답변 내용과 순위에 영향을 주지 않는다.
- 현재 공식 안내상 광고는 Free·Go 요금제의 성인 사용자에게 표시될 수 있다. Plus·Pro·Business·Enterprise·Edu와 만 18세 미만으로 확인된 이용자에게는 표시되지 않는다. 로그아웃 상태의 광고는 모든 사용자에게 적합한 범위로 제한된다.
- 광고주는 사용자의 채팅·채팅 기록·메모리·이름·이메일·정확한 위치·IP·민감정보를 받지 않는다.
- 광고 선택에는 현재 대화의 맥락과 의도, 랜딩페이지, 제목, 문구, 맥락 힌트, 타겟 설정 및 개인 최적화가 허용된 경우 일부 ChatGPT 이용 신호가 사용될 수 있다.
- 광고가 노출됐다고 해서 OpenAI가 광고주나 상품을 추천·보증한 것은 아니다.

## 3. 캠페인 구조와 설정

### 캠페인

캠페인에서 목표, 예산, 기간, 국가, 선택 플랫폼, 맞춤 잠재고객을 정한다.

- 목표: 조회수(CPM), 클릭수(CPC), 전환
- 전환 캠페인: oCPC 또는 이용 가능한 계정의 oCPM
- 예산: 평균 일일 예산 또는 캠페인 총예산
- 일정: 시작일·종료일
- 위치: 국가, 캠페인 유형과 국가에서 지원되는 경우 지역·도시·시장·우편번호
- 플랫폼: Android 앱·웹, 데스크톱 웹, iOS 앱·웹
- 맞춤 잠재고객: 자사 고객 목록 포함·제외

목표와 예산 유형, 전환 최적화 캠페인의 과금 모델과 전환 이벤트는 생성 후 변경이 제한될 수 있으므로 생성 전에 확정한다.

### 광고그룹

광고그룹은 제품·서비스·사용 상황·고객의 필요처럼 하나의 명확한 주제로 구성한다.

- 맥락 힌트: 제품이 무엇이고, 누구에게 도움이 되며, 언제 유용한지 자연어로 설명한다.
- 맥락 힌트는 정확히 일치하는 검색키워드도, 특정 대화에 노출을 보장하는 타겟 규칙도 아니다.
- 서로 다른 메시지나 랜딩페이지가 필요하면 광고그룹을 나눈다.
- 입찰: 수동 최대 CPC·CPM 또는 자격 계정의 성과 극대화 자동입찰

성과 극대화는 결과의 양을 우선하며 특정 CPC·CPA·ROAS를 보장하지 않는다. 비용 상한이 중요한 광고주는 수동 입찰을 우선 검토한다.

### 광고

광고는 광고주명·파비콘·제목·설명·랜딩페이지·이미지로 구성된다.

- 제목과 설명은 과장된 후킹보다 제공 가치, 대상, 유용한 상황을 구체적으로 설명한다.
- 같은 메시지를 반복하기보다 제품·서비스별로 서로 다른 효익과 사용 상황을 제시한다.
- 일반 홈페이지보다 광고 내용과 직접 연결되는 제품·서비스·콘텐츠 페이지를 사용한다.
- 소재별 UTM을 랜딩 URL에 직접 추가할 수 있다.
- 가이드형 생성 외에 대량 CSV 등록을 사용할 수 있다. 현재 공식 대량 등록 가이드의 소재 기준은 제목 16~24자 권장·최대 50자, 광고 문구 32~48자 권장·최대 100자, 정사각형 PNG/JPG 이미지 최대 1200×1200이다. 업로드 스키마와 실제 UI의 허용 범위는 집행 직전에 다시 확인한다.
- OAI-AdsBot과 OAI-SearchBot이 랜딩페이지를 확인할 수 있어야 한다.

## 4. 타겟팅

현재 공식 도움말에서 확인된 주요 타겟 설정은 국가·일부 세부 지역, 플랫폼, 맥락 힌트, 맞춤 잠재고객이다.

- 맞춤 잠재고객은 이메일·전화번호·해시값·GAID 목록으로 생성한다.
- 캠페인 수준에서 포함·제외할 수 있고, 광고그룹에서 잠재고객별 입찰가 조정을 지원할 수 있다.
- 포함 타겟팅은 일치 이용자 25,000명 이상의 최소 규모가 필요하다. 포함과 제외를 함께 쓰면 제외 후 남은 규모가 기준을 충족해야 한다.
- 포함 타겟팅과 입찰가 조정은 100,000명 이상의 오디언스를 권장한다. 25,000명 미만의 일치 오디언스도 제외 용도로 사용할 수 있다.
- 광고그룹의 맞춤 잠재고객 입찰 배수는 0.1배~10배 범위다. 여러 오디언스에 동시에 일치하면 가장 높은 배수가 적용된다. 입찰 배수는 게재 자격을 만드는 타겟 조건이 아니라 최대 입찰가 조정 기능이다.
- 일반적인 연령·성별·관심사 선택과 시간·요일별 게재 설정은 2026-09-17 공개 도움말에서 확인되지 않았다. 실제 계정 UI에서 제공 여부를 확인하기 전 제안하지 않는다.

## 5. 예산과 청구

- 원화 최소 일일 예산: 25,000원
- 일일 예산은 하루의 절대 한도가 아니라 7일간의 평균 일예산이다.
- 하루 최대 지출은 설정 일일 예산의 2배, 7일 최대 지출은 일일 예산의 7배다.
- 캠페인 총예산은 남은 기간과 게재 기회에 따라 페이싱된다. 전액 소진은 보장되지 않는다.
- CPC 캠페인은 공식 가이드에서 최대 CPC 미화 3~5달러를 시작 권장치로 제시하지만, 한국 시장의 예상 CPC나 성과 기준으로 사용하지 않는다.
- 카드 청구 시 임시 승인 보류가 발생할 수 있으며 최대 8일간 표시될 수 있다.
- 대한민국 세금계산서·부가세 처리, 대행사 후불 한도, 카드 명의 조건은 공개 도움말만으로 확정하지 않고 계정·인보이스에서 확인한다.

## 6. 전환 측정과 연계 기능

- Ads Manager에서 데이터 소스를 만들고 OpenAI Pixel, Conversions API 또는 둘 다로 이벤트를 보낸다.
- 측정 대상 예: 구매, 리드 제출, 가입 완료 및 지원되는 표준·맞춤 이벤트.
- OpenAI 클릭 참조값 `oppref`가 랜딩 URL에 추가될 수 있다. Pixel은 이를 자사 쿠키에 저장하며, 서버 이벤트에도 전달할 수 있다.
- Pixel과 Conversions API에 같은 이벤트를 함께 전송할 때 동일한 이벤트 ID로 중복 제거한다.
- Google Tag Manager로 Pixel 배포가 가능하다. 페이지 로드, 초기화, 이벤트 호출 순서를 점검한다.
- 자동 고급 매칭은 양식의 지원 고객 정보를 브라우저에서 SHA-256으로 정규화·해시 처리해 측정 보완에 사용할 수 있다.
- 앱 측정 파트너는 현재 AppsFlyer와 Adjust가 공식 안내돼 있다.
- 별도로 UTM을 사용해 GA4 등 기존 분석 도구에서 ChatGPT Ads 유입을 구분한다.
- Ads Manager의 캠페인·광고그룹·광고 설정에서 고정값과 `{campaign_id}`, `{ad_group_id}`, `{ad_id}`, `{ad_account_id}` 매크로를 랜딩 쿼리 매개변수에 추가할 수 있다. 광고 게재 시 자동 치환된다.
- 광고 URL에 이미 같은 매개변수가 있으면 상위 수준의 캠페인·광고그룹·광고 설정이 덮어쓰지 않는다. 공통 UTM 규칙과 동적 ID의 중복 여부를 출시 전에 점검한다.

권장 UTM 예시:

`utm_source=chatgpt&utm_medium=paid_chat&utm_campaign=[objective_product_period]&utm_content=[creative_message_version]`

UTM 명칭은 사내 규격과 GA4 맞춤 채널 그룹을 함께 정한다. `oppref`는 OpenAI 기여 측정용이며 UTM을 대체하지 않는다.

## 7. 리포트

캠페인·광고그룹·광고 수준에서 다음 항목을 확인하고 표·차트·CSV로 내보낼 수 있다.

- 노출수, 클릭수, 지출, CTR, 평균 CPC, 평균 CPM, 전환수
- `order_created` 기준 주문 매출과 ROAS
- 제공 계정의 1일 조회 후 전환 VTA 1d
- 플랫폼별 성과
- 일별 데이터 CSV

VTA 1d는 보조 지표이며 기본 전환수·CPA·입찰·청구·전환 최적화에 합산하지 않는다. 광고 클릭과 GA4 세션은 페이지 로드, 동의, 리디렉션, 브라우저 차단, UTM, 시간대와 기여기간 차이로 일치하지 않을 수 있다.

## 8. 대행사 온보딩 순서

1. 광고주 법인·결제 주체·국가·통화·시간대를 확정한다.
2. 광고주가 업무용 이메일로 별도 Ads Manager 계정을 생성한다.
3. 비즈니스 정보와 웹사이트·로고·업종을 입력하고 Persona 인증과 계정 심사를 완료한다.
4. 결제 프로필과 광고주 카드 정보를 등록한다.
5. 광고주가 대행사 담당자를 광고 계정 관리자 또는 멤버로 초대한다.
6. 광고 정책과 랜딩페이지 크롤러 접근을 점검한다.
7. Pixel·Conversions API·UTM을 설정하고 테스트 이벤트를 확인한다.
8. 목표·예산·기간·국가·플랫폼·잠재고객을 정해 캠페인을 만든다.
9. 고객 필요와 사용 상황별 광고그룹 및 맥락 힌트를 만든다.
10. 제목·설명·이미지·직접 랜딩페이지로 광고를 만들고 심사를 요청한다.
11. 게재 후 보고서와 GA4를 함께 확인하고 비용·전환 품질 기준으로 조정한다.

## 9. 미디어 믹스 제안 기준

ChatGPT Ads를 모든 광고주에게 기본 포함하지 않는다.

적합 가능성이 높은 경우:

- 사용자가 비교·탐색·문제 해결 대화를 거쳐 의사결정하는 고관여 상품이나 서비스
- 기존 검색키워드만으로 포착하기 어려운 자연어 요구와 사용 상황이 다양한 상품
- 제품·서비스별 구체적인 랜딩페이지와 설명 가능한 효익이 있는 광고주
- Pixel·Conversions API 또는 최소한 UTM·GA4 측정이 준비된 광고주
- 새로운 대화형 탐색 접점을 시험할 별도 예산이 있는 광고주

보수적으로 보거나 제외할 경우:

- 예산이 작아 원화 최소 일예산과 충분한 테스트 기간을 감당하기 어려운 경우
- 즉시 구매형 저관여 상품으로 검색·쇼핑광고가 더 직접적인 경우
- 전환 측정이나 직접 랜딩페이지가 준비되지 않은 경우
- 미성년자 도달이 핵심이거나 규제·민감 업종의 자격이 불확실한 경우
- ChatGPT 유료 요금제 사용자까지 광범위하게 도달한다고 전제한 경우

제안서에서는 ChatGPT Ads를 검색광고 대체재로 단정하지 않는다. `대화형 탐색·비교 단계에서 자연어 의도를 포착하는 신규 테스트 채널`로 정의하고, 검색·쇼핑·소셜 광고와의 역할 중복 및 예산 적정성을 검토한다.

## 10. 가비아CNS 제공 내러티브에서 추가 학습한 운영 관점

자료: `ChatGPT Ads Narrative_가비아CNS.pdf` 44페이지, 2026-09-17 검토. 문서에 `Confidential and proprietary`가 표시되어 있으므로 외부 제안서에서 수치·로드맵·사례를 그대로 재배포하거나 공개 출처처럼 인용하지 않는다. 공식 도움말로 현재 확인되는 기능만 운영 기준으로 승격하고, 나머지는 내부 영업·전략 참고로 분리한다.

### 공식 도움말과 일치하거나 추가 확인된 내용

- ChatGPT Ads의 차별점은 단순 검색어 포착보다 사용자의 질문 맥락, 해결 과제, 기대 결과와 의사결정 상황을 광고 관련성 신호로 활용하는 데 있다.
- 광고그룹은 제품명 중심으로만 쪼개기보다 `연관 주제 × 사용 사례 × 고객 여정 단계`를 기준으로 확장한다. 단, 메시지와 랜딩페이지가 실질적으로 달라지는 수준에서만 분리한다.
- 맞춤 오디언스 포함·제외와 광고그룹 입찰 배수를 함께 사용할 수 있다. 최소 25,000명, 포함·입찰 조정 권장 100,000명, 제외는 25,000명 미만도 가능하다는 기준을 적용한다.
- 동적 URL 매개변수로 캠페인·광고그룹·광고·계정 ID를 외부 분석 도구에 전달할 수 있다. UTM의 사람이 읽는 운영 규칙과 자동 ID 매크로를 함께 설계한다.
- 1일 조회 후 전환은 클릭 후 전환과 별도 지표이며 기본 전환·CPA·입찰·청구·최적화에는 합산되지 않는다.
- 혜택 중심 카피는 제품의 기능 나열보다 `누구의 어떤 문제를 언제 어떻게 해결하는가`를 설명해야 한다.

### 업종별 대화 의도 지도

미디어 믹스나 맥락 힌트를 설계할 때 다음 질문 유형을 출발점으로 삼는다.

- 리테일·소비재: 상품 발견, 비교, 적합성·호환성, 가격·가치, 재고·구매처, 성분·안전성, 사용 루틴
- 테크·B2B: 도구 비교, 상황별 솔루션, 비용 최적화, 도입·구현, 문제 진단, 사업 전략과 운영 의사결정
- 자동차: 부품 식별·호환성, 문제 진단, 정비·유지관리, 제품·공급사 선택, 구매 최적화
- 여행: 여행지 발견, 교통·숙소 비교, 활동·일정 계획, 준비와 제약 조건
- 로컬 서비스: 제공업체 탐색, 비교, 일정·이용 가능 여부, 예상 비용, 서비스 범위·자격
- 교육: 개념 학습, 문제 해결, 역량 개발 경로, 기관·프로그램 비교, 입학·자격 조건

이 지도는 광고가 노출되는 확정 카테고리나 타겟 목록이 아니다. 광고그룹 주제, 맥락 힌트, 소재 메시지와 랜딩페이지를 설계하는 가설 프레임으로만 사용한다.

### 내부 자료로만 보존하고 외부 확정 표현을 금지할 내용

- 생성형 AI 이용률 55%, 사용자 연령·직업·학력·기기 특성은 특정 조사와 내부 사용자 조사에 기반한 값이다. 한국 광고 도달 모수나 실제 광고 대상 구성으로 환산하지 않는다.
- 초기 광고주의 3배·7배 ROAS 사례는 업종, 예산, 기여기간, 분모와 표본이 충분히 공개되지 않았다. 성과 예측이나 목표 ROAS 근거로 사용하지 않는다.
- 40개 이상 국가 확대, 측정 파트너십 고도화, 스폰서드 에이전트 등은 자료 작성 시점의 로드맵이다. 현재 제공 기능으로 제안하지 않는다.
- PDF의 제목 32자·카피 54자 권장 표시는 현재 공식 대량 등록 가이드와 다르다. 최신 공식 기준인 제목 16~24자 권장·최대 50자, 문구 32~48자 권장·최대 100자를 우선한다.
- ‘제품 피드와 기타 테스트 형식’은 계정 자격과 현재 UI를 확인한 뒤에만 제안한다.
